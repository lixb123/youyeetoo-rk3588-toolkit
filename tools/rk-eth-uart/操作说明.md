# RK3588 以太网 UART 联调工具操作说明

## 1. 工具位置与作用

工具目录：`<workspace>\tools\rk-eth-uart`

双击 `start.bat` 启动。工具通过电脑 `COM3` 的 UART 控制 RK3588，默认参数是 `1500000 8N1、无流控`。界面分成两块：

- 左侧“网口发送控制”：选择业务、源/目标 IP、物理网口、协议类型并发送。
- 右侧“板端网口接收内容”：显示 RK3588 网关实际从 `eth0/eth1` 收到的数据内容、源/目标 IP、UDP 端口、优先级、完整 `data_hex` 和可打印文本。

## 2. 测试前的物理连接

- UART：电脑 `COM3` <-> RK3588 UART，保持串口工具或本工具二选一占用。
- 电脑“以太网 3” <-> RK3588 `eth0`，载荷/N6/管理/S1 业务。
- 电脑“以太网” <-> RK3588 `eth1`，X 测控业务。

电脑模拟地址应保持如下配置：

| 角色 | 电脑地址 | RK3588 地址 | 网口 |
|---|---|---|---|
| 载荷模拟 | 10.240.1.38、.35、.37、.39 | 10.240.1.34/24 | eth0 |
| X 测控模拟 | 10.240.1.2/30 | 10.240.1.1/30 | eth1 |

若还没有配置，在管理员 PowerShell 中执行：

```powershell
cd <workspace>\tools\eth-sim
Set-ExecutionPolicy -Scope Process Bypass
.\setup_interfaces.ps1
```

## 3. 首次连接板端

1. 关闭其他串口工具，双击 `rk-eth-uart\start.bat`。
2. 确认 UART 当前已经登录到 RK3588 的 `root` shell；在左上角填写 `COM3`、`1500000`，点击“连接 UART”。
3. 点击“启动/确认板端网关”。工具会确认 `/home/youyeetoo/youyeetoo_eth_gateway` 中的网关正在运行。
4. 点击“读取板端状态”，右下角应看到：

```text
eth0 10.240.1.34/24
eth1 10.240.1.1/30
qdisc prio ... bands 4
```

若网关目录或地址不正确，先在 UART shell 执行：

```sh
cd /home/youyeetoo/youyeetoo_eth_gateway
sudo ./configure_gateway.sh eth0 eth1
```

## 4. 发送协议数据

### 4.1 X 测控应答

选择“X 测控 / 平台应答”，默认显示：

```text
源 IP 10.240.1.36
目标 IP 10.240.1.2
网口 eth1
协议应答 1ACF
```

指令码填写 `001D`，参数可留空。点击“打包并发送”。界面会生成大端协议帧：

```text
1A CF 03 D0 C0 00 00 01 00 1D FE 4E
```

RK3588 会通过 UART 执行 Python UDP 发送命令，实际从 `eth1` 发出。发送前程序会把业务源 IP 以 `/32` 临时加到指定接口，发送结束立即删除；如果地址原本存在则不会删除。

### 4.2 X 测控指令或文件分段

- 选择“协议指令 EB90”，例如指令码 `0101`，参数输入 `01 02`。
- 选择“文件分段”，指令码/块号填写 `0`，数据输入不超过 1000 字节，并填写分组标志 `1/0/2` 和序号。

工具自动计算协议长度和校验和。界面底部会显示实际发送的完整十六进制内容。

### 4.3 业务透传

选择 N6、S1、基站管理或核心网管理业务。工具自动切换相应源/目标 IP、网口和优先级。选择“业务透传”后：

- 选择“UTF-8 文本”，直接输入业务文本；或
- 选择“十六进制”，输入例如 `01 02 A0 FF`。

业务透传不会添加 `EB90/1ACF` 协议头；协议帧则由工具严格生成并带校验和。

## 5. 接收数据显示

电脑端 `eth-sim` 或其他终端向 RK3588 发送 UDP `47000` 数据后，右侧接收区会显示类似：

```text
RX iface=eth1 10.240.1.2 -> 10.240.1.36 proto=17 bytes=60 priority=0 flow=upload/platform-interaction
RX data_hex=EB9003D0C0000001001DFE4E
RX text=.........
DATA ... checksum=ok ... opcode=0x001D
```

界面只展示板端日志中的实际接收内容。网关对 `PACKET_OUTGOING` 会过滤，因此板端自己发出的包不会被误显示为接收包；电脑另一端收到的包才是发送验证依据。

## 6. 结束测试

1. 保存或复制右侧日志内容。
2. 点击“断开”释放 `COM3`。
3. 在管理员 PowerShell 清理电脑模拟地址：

```powershell
cd <workspace>\tools\eth-sim
.\setup_interfaces.ps1 -Clear
```

## 7. 注意事项

- `10.240.1.34` 和 UDP `47000` 是当前 Demo 约定值，不等同于最终 ICD。
- 协议多字节字段均按大端编码；校验和不包含 `EB90/1ACF` 标识符。
- 当前 `tc prio` 是软件队列；板端网卡仍只有一个活动 TX 硬件队列，不代表已实现硬件多队列、PFC 或 PAUSE。
- 不要同时打开串口工具和本程序，否则 `COM3` 会被占用。发送功能需要当前 UART 会话是 `root` shell。
