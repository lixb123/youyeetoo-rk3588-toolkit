# RK3588 相机 UART 控制台

## 功能

这个工具通过电脑串口控制 RK3588 板端的 `youyeetoo-app.service`，用于影石相机联调：

- 自动枚举电脑上的 COM 口，默认选择 `COM3`。
- 默认串口参数为 `1500000 8N1`、无流控。
- “刷新相机”发送 `CAMERA_LIST_DEVICES`，读取板端设备 JSON，显示序列号、型号、固件和能力。
- 可发送初始化、状态、电量、存储、拍照、录像、媒体列表和参数配置命令。
- 可填写 `camera_serial` 精确控制多台 X5 或混合型号设备。
- 底部日志显示板端 shell 回显、命令反馈和 JSON 解析结果。
- 每条指令等待板端反馈最长 45 秒；设备发现会等待 8 秒以覆盖 CameraSDK worker 的实际执行时间。

## 启动

双击 `启动 rk-cam-uart.bat`。启动器会优先使用 PowerShell 7；未安装 PowerShell 7 时，会让 Windows PowerShell 5.1 以 UTF-8 方式加载脚本。如果 Windows 阻止脚本运行，右键 PowerShell 后执行：

```powershell
pwsh.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\rk-cam-uart.ps1
```

使用前关闭其他占用 COM3 的串口工具。板端必须已经启动 Linux 控制台和 `youyeetoo-app.service`。

## 推荐流程

1. 连接开发板 UART，确认波特率 `1500000`。
2. 点击“连接”。如果看到 `debug>`，点击“恢复 console”，直到日志出现 Linux shell 回显。
3. 点击“刷新相机”，确认列表中的 `serial`、`model_key` 和 `capabilities`。
4. 对单台相机可直接发送命令；多台相机必须在“目标序列号”中填写唯一 `camera_serial`。
5. 先执行 `CAMERA_INIT`、状态、电量、存储，再执行拍照/录像等有状态操作。

附加参数示例：`CAMERA_SET_MODE` 填 `mode=photo_single`，`CAMERA_VIDEO_START` 可填 `resolution=5.7k30 bitrate=120000000`。点击设备表格中的一行会自动填入该相机序列号。

## 重要边界

`dispatch_ok` 只表示板端收到了命令，不代表 SDK 调用成功。要以日志中 worker 完成、`connected=yes` 和实际结果为准。相机从 `lsusb` 消失时停止连续查询，检查供电、USB 线、Hub 和物理端口。

当前程序支持 CameraSDK 2.1.1 可识别的 One X、One R、One RS、One X2、X3、X4、X5、X4 Air 和 Unknown。基础状态、拍照、普通录像和媒体操作走通用 SDK；扩展模式按型号能力判断，未验证型号会返回不支持错误。

本工具只通过 UART 发送板端命令，不烧录固件、不改分区、不升级相机固件、不删除媒体。运行 `CameraSDKTest` 前必须停止正式服务，避免 CameraSDK 争用。

## 反馈为空时

- 检查是否选择了正确 COM 口，尤其是 `COM3`。
- 检查串口参数是否为 `1500000 8N1`、无流控。
- 若界面日志显示 `debug>`，点击“恢复 console”。
- 通过板端串口确认 `systemctl is-active youyeetoo-app.service`。
- 没有相机时列表为空是正常结果；不要把空列表当成型号不支持。
