## Decision Status

- `CONFIRMED`: supported by the current authoritative source.
- `CONFLICT`: two sources disagree; do not implement silently.
- `MISSING`: required for implementation but not specified.
- `DEMO_ASSUMPTION`: selected only to make a test/demo run.
- `STALE`: historical value superseded by newer evidence.
